# Machine Learning From Scratch

I’m currently learning about neural networks and machine learning, and I’m also taking an AI in Medicine course.

I created this repository to connect what I’m learning in class with hands-on practice. My goal is to better understand the math behind the models, become more comfortable writing Python code, and build confidence explaining how everything works.

I’m starting from the basics and documenting my progress, questions, and mistakes along the way. 

## My goal

Build a small machine-learning project from beginning to end:
understand the math, write the code, train a model, and evaluate its predictions.

## Learning plan

- [ ] Understand inputs, predictions, weights, and bias
- [ ] Calculate a prediction by hand
- [ ] Reproduce the calculation in Python
- [ ] Understand loss: how we measure prediction errors
- [ ] Learn how training updates weights and bias
- [ ] Practice with a public real-world dataset
- [ ] Evaluate the model using data it did not train on
- [ ] Make graphs and explain the results and limitations

## How I’ll document each lesson

1. What I’m trying to learn
2. A simple explanation in my own words
3. The math worked out step by step
4. Python code for the same calculation
5. Results, mistakes, and what I learned

## Data

Early exercises will use clearly labeled fictional numbers.
Later exercises will use a public dataset, with its source
and usage terms documented here.

This repository will not contain confidential research data,
internal team materials, or unpublished research results.

## Current progress

I’m beginning with one input, one weight, and one bias.
The first task is to understand how these produce a prediction.
